CyberVaras 2026 :: OSINT :: El Repo Olvidado

Un desarrollador subió una credencial a un repositorio público y luego la "borró"
en un commit posterior. Pero git conserva el historial completo.

  Repositorio: [COMPLETAR POR LA ORGANIZACIÓN — URL del repo sembrado]

Pasos sugeridos:
  git clone <repo> && cd <repo>
  git log --oneline --all
  git log -p            # o: git show <commit_que_agrego_la_flag>

La flag (formato CITT{...}) está en el contenido de un archivo eliminado.
