## Enunciado (para el jugador)

Te damos el nombre de un personaje ficticio que creamos para el campeonato. Usa el mismo alias en varias plataformas. Síguele el rastro hasta donde dejó la flag.

## Solución (writeup — NO publicar)

A partir del alias, buscar con sherlock/whatsmyname el perfil en varias redes (todas controladas por la organización). En la bio/último post de una de ellas está la flag.
